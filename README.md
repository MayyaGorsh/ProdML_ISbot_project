# Бот или человек

Модель оценивает вероятность того, что участник короткого диалога является ботом. Для каждого участника test она создаёт строку ID,is_bot в файле submission.csv. Метрика соревнования - logloss, меньше лучше.

## Единый e2e-запуск

Из корня проекта. Первую команду достаточно выполнить один раз, вторая запускает весь эксперимент:

```powershell
uv sync --locked
uv run --locked main.py --svd-iterations 800 --output-dir outputs/e2e_run
```

main.py проверяет структуру входных json и csv через pydantic, собирает признаки с помощью polars, сохраняет подготовленные таблицы в parquet, обучает модели, считает OOF и создаёт outputs/e2e_run/submission.csv, результаты кросс-валидации, модели и журнал mlflow. Каждый повторный запуск лучше направлять в новую папку, чтобы сохранить предыдущие результаты. Параметры запуска показывает uv run main.py --help. Версии зависимостей закреплены в uv.lock.

Для каждого участника используются 52 числовых признака. Часть описывает длину и состав текста, часть - порядок ходов и реакцию на предыдущую реплику собеседника. Символьный tf-idf по n-граммам длиной 2-5 сжимается методом svd до 48 компонент. На них вместе с числовыми признаками обучается catboost. Итоговое предсказание смешивает его вероятность с числовым catboost и логистической регрессией на словном и символьном tf-idf.

Валидация идёт по диалогам. Оба участника одной беседы всегда находятся в одном фолде. Словари tf-idf и svd строятся заново внутри каждого фолда. Четыре OOF-прогноза объединяются для расчёта logloss.

## mlflow

После завершения эксперимента запусти интерфейс из корня проекта:

```powershell
uv run --locked mlflow ui --backend-store-uri sqlite:///outputs/e2e_run/mlflow.db --host 127.0.0.1 --port 5000
```

Открой http://127.0.0.1:5000. Если для эксперимента выбрана другая папка, замени путь к базе. Остановить сервер можно через Ctrl+C.

## Исследования

Исследовательский код находится в ноутбуках. Для работы в jupyter или редакторе с поддержкой ipynb установи дополнительные зависимости:

```powershell
uv sync --locked --extra notebooks
```

Ноутбуки запускаются из корня проекта и используют этот Python-интерпретатор:

- 01_eda.ipynb - длины реплик, порядок ходов, повторы, сдвиг train/test, ошибки и калибровка.
- 02_features.ipynb - абляция групп, неопределённость оценок, новые признаки и графики зависимости метки от признаков.
- 03_models.ipynb - другие архитектуры, регуляризация и число деревьев.

Пересчёт модельных опытов занимает заметное время и обновляет файлы в outputs/analysis и журнал mlflow. Для просмотра результатов достаточно открыть сохранённые ноутбуки и графики.

## Файлы

- main.py - вход в пайплайн
- features.py - вычисление дополнительных признаков
- в data лежат исходные наборы
- в outputs сохранены метрики версий, финальный сабмит и данные для повторного запуска ноутбуков
- outputs/analysis содержит результаты исследований
- остальные модели и журнал mlflow создаются при запуске main.py
- defense содержит презентацию и графики
